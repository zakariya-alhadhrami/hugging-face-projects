
# 🤗 Hugging Face Projects Repository

A collection of **machine learning and AI projects** built using the **Hugging Face ecosystem**.
This repository serves as a growing portfolio of experiments, models, and demos created for learning, practice, and deployment.

---


## 📚 Projects

| Project                     | Description                                                                                                                                                                                                                                                | Dataset | Model | Demo | README.md |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- | ----- | ---- | ------------ |
| **Food Not Food** |Food Not Food is a simple text classification project that predicts whether a sentence is related to food or not using a fine-tuned transformer model. | [Dataset](https://huggingface.co/datasets/mrdbourke/learn_hf_food_not_food_image_captions) | [Model](https://huggingface.co/Zakariya007/hf_food_not_food_distilbert_base_uncased) | [Demo](https://huggingface.co/spaces/Zakariya007/Food_Not_Food_Classifier) | [README.md](https://github.com/zakariya-alhadhrami/hugging-face-projects/tree/main/demos/text_classifier) |
|  **Trashify** | Trashify is an AI-powered object detection tool designed to incentivize local cleanup efforts. By using state-of-the-art computer vision, the app validates real-world cleaning actions in real-time. | [Dataset](https://huggingface.co/datasets/mrdbourke/trashify_manual_labelled_images) | [Model](https://huggingface.co/Zakariya007/rt_detrv2_finetuned_trashify_box_detector_v1) | --- | [README.md](https://github.com/zakariya-alhadhrami/hugging-face-projects/tree/main/demos/object%20detection) |
